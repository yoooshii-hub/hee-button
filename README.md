# へぇボタン（イベント用）

トリビアの泉風の「へぇボタン」を、参加者のスマホから押してもらい、会場の画面にリアルタイムで合計を表示するアプリです。

構成: Node.js + Express + Socket.IO（1台のサーバーで完結、データは `data/db.json` に保存）

## 起動

```bash
npm install
npm start          # http://localhost:3000
```

| 環境変数 | 説明 |
| --- | --- |
| `PORT` | 待ち受けポート（既定 3000） |
| `PUBLIC_URL` | QRコードに埋め込む公開URL（例 `https://hee.example.com`）。未設定ならアクセスされたホスト名を使います |
| `DATA_DIR` | データ保存先（既定 `./data`） |

## 使い方

1. `/` で管理者アカウントを作成 → マイルームへ
2. イベントを作成すると、参加者用URL・QRコード・合計表示ページURLが発行されます
3. 合計表示ページを会場スクリーンに映し、QRコードを参加者に読み取ってもらいます
4. 「開始」で参加者がボタンを押せるようになります。「一時停止」で受付を止め、「リセット」で合計と参加者の回数を 0 に戻します（再び「開始」するまで押せません）

## ページ

| URL | 対象 | 内容 |
| --- | --- | --- |
| `/` | 管理者 | ログイン / アカウント作成 |
| `/room` | 管理者 | マイルーム（イベント一覧・作成） |
| `/room/events/:id` | 管理者 | 開始・一時停止・リセット、URL / QR、ライブ合計 |
| `/display/:slug?key=…` | 会場スクリーン | 合計表示（カウントアップ、舞い上がる「へぇ」、盛り上がりメーター、参加用QR） |
| `/e/:slug` | 参加者 | へぇボタン（ログイン不要、自分の回数のみ表示） |

## 音について

ボタン音は Web Audio で「へぇ」風の声を合成しています。好きな音源を使いたい場合は `public/sounds/hee.mp3` を置くと自動でそちらを使います（番組の音声など著作物の利用はご注意ください）。iPhone はマナーモード中だと音が鳴りません。

## 仕様メモ

- 参加者の回数はページ内だけで保持するため、リロードやブラウザを閉じると 0 に戻ります
- 連打対策として 1 接続あたり毎秒 15 回までをカウントします（`server.js` の `MAX_PRESSES_PER_SEC`）
- 押下は 100ms ごとにまとめて表示側へ送るので、大人数でも負荷が上がりにくい作りです

## デプロイ

WebSocket が使えて、プロセスが常駐する Node.js ホスティングが必要です（Vercel / Netlify のサーバーレスは不向き）。

- **Render**: 同梱の `render.yaml` を使えば、GitHub リポジトリを接続するだけで起動します。無料プランはディスクが保存されず、しばらくアクセスがないと停止するため、アカウントやイベントが消えることがあります。いつでも使える状態で残すには有料プランに永続ディスクを付け、`DATA_DIR` をそのディスクに向けてください
- **Railway / Fly.io**: リポジトリを接続し、起動コマンド `npm start`。`data/` を永続ディスク（ボリューム）に割り当てるとアカウントやイベントが再デプロイ後も残ります
- **VPS（さくら、ConoHa、Lightsail など）**: `npm install && PORT=3000 npm start` を pm2 や systemd で常駐させ、nginx などで HTTPS 化
- **当日だけ手元のPCで**: `npm start` してから `cloudflared tunnel --url http://localhost:3000` などで一時的な公開URLを発行

サーバーは 1 台で動かしてください（複数台に分けるとカウントが分散します）。
